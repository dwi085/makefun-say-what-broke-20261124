One line of software error copy that tells the user the brutal truth about what went wrong — a save that failed because the disk is full, the backup was a shortcut, and autosave called in sick — and makes them laugh on the way. Written for make.fun's "Say What Actually Broke" bounty, judged pairwise by a house judge on truth, humour, and whether a team would actually ship it in a dialog.

## Run it

```sh
node main.ts
```

It writes exactly one line (at most 200 characters) to `/output/entry.txt`, or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when set. Deterministic: two runs produce byte-identical output. No network.
